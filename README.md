# 🚌 BUSSS

A simple game inspired by the classic Snake, reimagined for Metro riders.

## About

BUSSS is designed to help people pass the time while waiting for the bus. Take a break from doomscrolling. Pick up passengers, avoid construction zones, and see how long you can keep your bus running!

## How to Play

- **Swipe** to change direction (works on mobile and desktop)
- **Pick up passengers** 🧍 to grow your bus and score points (+10 points each)
- **Drop off at bus stops** 🚏 to shrink your bus and score bonus points (+15 per passenger)
- **Avoid construction zones** 🚧 - they'll end your run!
- **Don't crash** into yourself
- The game speeds up every 100 points

## Features

- 🎮 Simple swipe controls optimized for mobile
- 🚌 Retro pixel art LA Metro bus with authentic colors
- 🚧 Dynamic construction zones that appear and disappear
- 🎵 Original chiptune soundtrack that speeds up as the game does
- 🏆 Global leaderboard with initials, emoji, and city
- 📱 Full-screen on any phone size
- ⚡ Progressive difficulty — speeds up every 10 passengers

## Why BUSSS?

This game was created with a simple goal: give bus riders something fun and engaging to do while waiting, without the negativity of endless social media scrolling.

## Technical Details

- Built with vanilla HTML5, CSS, and JavaScript
- Uses Canvas API for rendering
- Web Audio API for procedurally generated chiptune music and sound effects
- Supabase for global leaderboard
- No frameworks, no dependencies, no build process
- Single HTML file for maximum simplicity
